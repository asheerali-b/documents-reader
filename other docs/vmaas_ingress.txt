General Ingress Rule
Like in public clouds we manage all the ingress traffic to virtual machines within Bosch Private Cloud. That means that ingress to virtual machines is only enabled where necessary.

Overall we need to distinguish between ingress from external and ingress between virtual machines.

This requires a so-called floating IP for the virtual machine. Such a floating IP is assigned to Jump Host virtual machines by default, but for workload virtual machines get a floating IP only when bound to an application in Cloud Foundry or if configured to allow ingress.

Communication from other Virtual Machines
The communication from all other virtual machines within the same organization is possible via ICMP, TCP and UDP on all ports. Communication from virtual machines in other organizations is not allowed by default, but you can enable the ingress to allow this communication.

Communication from the Internet
Virtual machines are not directly reachable from the Internet, as no public IP addresses are used. To expose a service running on a virtual machine to the Internet you need a Load Balancer as a Service in addition, that is the interface to the Internet.

Communication from other services in Bosch Private Cloud
Communication from other services in the Bosch Private Cloud is by default not enabled, but you can configure the ingress for your virtual machine to enable this.

Communication from Enterprise IT
Communication from Enterprise IT in general is possible, but on VMaaS virtual machines only enabled for Jump Hosts - Linux Jump Hosts: SSH (22) and Windows Jump Hosts: RDP (3389). In addition, ingress can be managed in self-service via Management REST API.
