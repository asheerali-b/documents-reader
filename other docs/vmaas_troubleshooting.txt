Network Connectivity
Ping - ICMP traffic is allowed within the customer tenant. Your should be able to ping other VMs in your tenant as well as the default gateway.

Netstat - you can verify which ports are listening on your VM by using the netstat command. The following table lists several common netstat commands.

netstat -a

netstat -a

List all ports and connections

netstat -l

n/a

List only listening ports

netstat -p

netstat -b / netstat -o

Display the PID or process which is creating the connection

netstat -lp

n/a

List all programs which are listening

netstat -n

netstat -n

Display numerical addresses

netstat -an

grep ':[port number]'

Find a process using a particular port

NOTE

For more information on how to use the netstat command, checkout these websites:
Linux: https://phoenixnap.com/kb/netstat-command
Windows: https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/netstat

Temporarily stop the Linux firewall:



sudo systemctl stop firewalld 

To start the Linux firewall:
 



sudo systemctl start firewalld
Temporarily disable SELinux:



setenforce 0 

Enable SELinux:



setenforce 1 

NOTE

Permanently disabling the firewall or SELinux increases security risks. Please only disable these features temporarily.
