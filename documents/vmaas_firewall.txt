Firewall on a Linux VMaaS VM
Created by 

 De Winter Commerina Aletta (BD/ISA-PRC2) on 2026, Feb 06  1 minute read Current Version V 1Page Info
The firewall in the RHEL systems is enabled by default. We do not recommend disabling the firewall but suggest to add the ports needed for the applications to help prevent unwanted attacks on the BHC environment.

You can use firewall-cmd to show or change the settings of firewalld.

The following is the basic syntax of the firewall-cmd command:



Usage: firewall-cmd [OPTIONS…​]

Here is a list of some common options you might need when working with firewalld:

NOTE

To make a setting remain active after a restart of the service or reboot, you will need to add --permanent to the commands which change settings



Status Options



firewall-cmd --state                  Return and print firewalld state.
firewall-cmd --reload                 Reload firewall and keep state information.
firewall-cmd --complete-reload        Reload firewall and lose state information.
firewall-cmd --runtime-to-permanent   Create permanent from runtime configuration.
firewall-cmd --check-config           Check permanent configuration for errors.
firewall-cmd --list-all               Show the current running state. 

Service Options (ports or protocols used together)



firewall-cmd --info-service=<service>                        Print information about the <service> service.
firewall-cmd --new-service=<service>                         Add a new permanent and empty service.
firewall-cmd --service=<service> --get-protocols             List protocols assigned to the <service> service.
firewall-cmd --service=<service> --add-protocol=<protocol>   Add a new protocol to the permanent service.
firewall-cmd --service=<service> --get-ports                 List protocols assigned to the <service> service.
firewall-cmd --service=<service> --add-port=<port>           Add a new port to the permanent service. 

Panic Options



firewall-cmd --panic-on           Enable panic mode.
firewall-cmd --panic-off          Disable panic mode.
firewall-cmd --query-panic        Query whether panic mode is enabled. 

NOTE

The firewall configuration can be a simple or complex as you would choose.

Additional resources on firewalld is available with the following links:

https://fedoraproject.org/wiki/Firewalld

https://www.redhat.com/sysadmin/beginners-guide-firewalld
